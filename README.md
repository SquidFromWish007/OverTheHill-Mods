# Over the Hill mods by SquidFromWish

`versions.json` holds the latest version of each mod. The mods read it once per launch to show
"Update x.y on Nexus" in their menu. An optional `<mod>_important` message also shows a small
popup after loading a save, for important fixes. `<mod>_url` adds an "Open Nexus" button to it.

The mods themselves are on Nexus Mods.
